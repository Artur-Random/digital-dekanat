# Инструменты

ИИ-инструменты, IDE, сервисы и библиотеки, которые использовались при создании прототипа. Версии библиотек: [docs/licenses.md](../licenses.md).

## ИИ-инструменты

| Инструмент                                 | Для чего использован                                                                 | На каком этапе                           |
| ------------------------------------------ | ------------------------------------------------------------------------------------ | ---------------------------------------- |
| Claude (чат проекта), роль «архитектор»    | Спецификация, реестр норм, задания для Claude Code, проверка результата              | Все этапы, с 10.11                       |
| Claude Code (облачная сессия)              | Исполнитель: весь код, тесты, документы процесса, PR и слияние в main                | Задания 1–2 и далее                      |
| Субагент `security-reviewer` (Claude Code) | Проверка изменений по разделу «Безопасность» CLAUDE.md                               | После каждой фичи, с задания 1           |
| Субагент `ui-reviewer` (Claude Code)       | Проверка 360 px, состояний экранов, доступности, плашки                              | После изменений интерфейса, с задания 1  |
| Субагент `norms-checker` (Claude Code)     | Сверка утверждений о правилах с реестром норм                                        | После текстов о правилах (с заданий 4–5) |
| Хук `log-prompt` (Claude Code)             | Дословная запись промптов в `docs/process/prompts.md` с маскированием секретов       | С задания 1                              |
