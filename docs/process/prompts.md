- permissions по минимуму, concurrency для деплоя (два деплоя не идут параллельно).
- Подключение по SSH только со StrictHostKeyChecking=yes и known_hosts из секрета. Отключать проверку ключа хоста запрещено.
- Ни один шаг не печатает секреты, содержимое .env и вывод команд, где они могут оказаться.
- Демо-пароли для e2e в CI генерируются случайно в каждом прогоне, сразу скрываются через ::add-mask:: и живут только в окружении прогона. В секреты GitHub и в репозиторий они не попадают.
