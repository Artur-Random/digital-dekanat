4. Хук записи промптов

- Скрипт НИЧЕГО не печатает в stdout: по документации при коде 0 stdout попадает в контекст модели.
- Всегда завершается с кодом 0. При ошибке записи пишет причину в stderr и не блокирует промпт.
- Маскирует очевидные секреты, заменяя их на [СКРЫТО]: токены GitHub (ghp_, github_pat_), приватные ключи (-----BEGIN ... PRIVATE KEY-----), ключи и токены Yandex Cloud (AQVN..., t1....), пары вида password=..., secret=..., token=... Если что-то скрыто, добавляет под заголовком строку «(в промпте скрыты секреты)».
