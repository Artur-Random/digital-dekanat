# Шаблон замечания (тестировщик Максим)

Максим тестирует развёрнутый сайт https://studcab.ru с телефона. Доступа к репозиторию у него нет: замечания он присылает Кириллу по этому шаблону, Кирилл передаёт их в чат Claude Code, Claude Code заводит по одному issue на замечание (правило: CLAUDE.md, «Замечания через Issues»).

Одно замечание — один блок. Пароли не пишем и не показываем на скриншотах.

```
Экран: (например, «Главная», «Расписание → Неделя», адрес страницы)
Телефон и браузер: (например, iPhone 13, Safari; Android, Chrome)
Аккаунт: alina / denis / mfc / dekanat
Что делал: (по шагам)
Что ожидал:
Что получилось:
Важность: блокер / важно / мелочь
Скриншот: (приложить картинку; без паролей)
```

Важность:

- **блокер** (`severity:blocker`): экран не открывается, данные чужого пользователя, нельзя пройти сценарий;
- **важно** (`severity:major`): сценарий проходит, но с ошибкой в данных, сроках, тексте о правилах или вёрстке, которая мешает пользоваться;
- **мелочь** (`severity:minor`): опечатка, отступ, неудачная формулировка.

В issue Claude Code добавляет строку «Источник: Максим, передал Кирилл, ДД.ММ.ГГГГ» и метки `max-review` и `severity:*`. Скриншоты лежат в `docs/process/max-review/<номер issue>-<n>.png`.
