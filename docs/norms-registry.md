# Реестр норм: «Кабинет, который предупреждает заранее»

Версия 2, 10.11.2026. Статус: частично сверено Кириллом (отмечено ✓).

## Как читать

- **Цитата** приведена дословно по тексту документа. Исправлены только склейки слов из распознавания («обязаныликвидировать» → «обязаны ликвидировать») и убраны одиночные тире-артефакты выравнивания внутри фраз (в N-27, N-45, N-47 в тексте слоя стоит «при наличии — документов», «присвоенного — обучающемуся»). Остальная пунктуация оригинала сохранена.
- **Источник текста:** «текстовый слой» значит, что текст взят из PDF; «OCR» значит, что документ сканированный и распознан Tesseract. Цитаты с пометкой OCR сверять особенно внимательно.
- **Стр.** указана по PDF-файлу, а не по колонтитулу.
- **Где используется:** экран или текст кабинета. Код S относится к экранам студента, E к экранам сотрудника (см. spec-v1.md, раздел 2).
- **Правило для кабинета:** в интерфейсе ссылка на пункт ставится только к утверждению из этого реестра. Всё остальное помечается как «так устроено в прототипе».

Колонка «Сверено» заполняется Кириллом: ✓ совпадает, ✗ ошибка (с пояснением).
